# LoRA 与参数高效微调笔记

## 1. 核心思想
LoRA（Low-Rank Adaptation）冻结预训练权重 W，在旁路注入两个低秩矩阵 A 与 B，
把增量写成 ΔW = B·A，其中 B 的形状是 d×r，A 的形状是 r×k。训练时只更新 A 与 B。

## 2. 关键超参数
- 秩 r：控制低秩瓶颈的宽度。实践中最常用的取值是 8 或 16；r 越大表达能力越强，但参数量与显存占用上升。
- 缩放系数 alpha：实际增量会乘以 alpha / r。常见做法是把 alpha 设为 r 的 1 倍到 2 倍，例如 r=8 时 alpha 取 8 或 16。
- dropout：作用在 LoRA 旁路上，常用 0.05 到 0.1，用于抑制小数据集过拟合。
- 目标模块：通常注入到注意力的 q_proj、v_proj，也可以扩展到 k_proj、o_proj 与 FFN。

## 3. QLoRA
QLoRA 在 4bit 量化的基座模型上训练 LoRA 适配器，通过 NF4 量化、双重量化与分页优化器，
把 7B 模型的微调显存需求压缩到单张 24GB 甚至更小的显卡。代价是训练速度略慢。

## 4. 常见误区
1. 只比较 LoRA 与 QLoRA 的最终分数而不控制学习率：学习率未收敛会把结论带偏。
2. 认为 r 越大越好：在数据量有限时，过大的 r 更容易过拟合。
3. 忽略 alpha / r 的比例：换 r 之后不同步调整 alpha，会改变等效学习率。

## 5. 评测建议
在同一份留出集上比较，报告任务指标、显存峰值、训练时长与推理延迟，
并固定随机种子与早停策略。结构类任务还要单独统计格式合规率。
